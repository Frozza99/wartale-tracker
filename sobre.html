Como funciona o Ledger de Ascensão

Esse site acompanha diariamente os personagens de nível 160 a 178 do Wartale (servidor de Priston Tale), mostrando progresso, ganho de EXP e comparação entre jogadores.

DE ONDE VÊM OS DADOS

O ranking Top Level vem direto da API oficial do Wartale — os mesmos dados que alimentam o ranking do site oficial. Nível, EXP e porcentagem de progresso são exatos, não estimados.

Rankings extras (mineração, pesca, PvP) vêm do ranking público exibido em wartale.com/ranking.

COM QUE FREQUÊNCIA ATUALIZA

Uma rotina automática busca os dados a cada 30 minutos e salva um novo registro. Não é instantâneo — o GitHub (que hospeda essa automação de graça) não garante o minuto exato, então pode haver alguns minutos de atraso.

O QUE SIGNIFICA "TRI"

É a forma abreviada de "trilhões" de EXP — nos níveis mais altos do jogo, a experiência necessária passa a ser contada em trilhões, então usamos "tri" como unidade (ex: 34.99 tri = 34.994.646.404.461.99... pontos de EXP).

SOBRE O RANKING DE CLÃS

É calculado agrupando os personagens rastreados pelo nome do clã. Só entram nesse cálculo os clãs de personagens que aparecem no ranking Top Level — não é uma contagem de clã completa do servidor.

SOBRE A PREVISÃO ("RITMO MÉDIO")

É uma estimativa baseada no ritmo de ganho de EXP dos últimos dias daquele personagem — não é garantia de nada, só uma projeção simples caso o ritmo se mantenha igual.

LIMITAÇÕES CONHECIDAS

  • Se um personagem ficar off-line/sem aparecer no ranking por um tempo, o histórico dele fica pausado até reaparecer.
  • O mapeamento de classe (número → nome) foi inferido pela ordem oficial dos ícones do site, não veio confirmado na documentação da API.

Site não-oficial, feito por fãs. Não tem afiliação com a equipe do Wartale.
